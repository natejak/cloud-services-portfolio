# Cloud Services Portfolio ☁️

Welcome to my Cloud Services portfolio!

I am studying Information and Communication Technology at
Oulu University of Applied Sciences (OAMK), Finland.

This page presents my practical assignments from the
Cloud Services course.

## My Projects

### Week 1 – Cloud Computing Fundamentals

Introduction to cloud computing, including:

- Infrastructure as a Service (IaaS)
- Platform as a Service (PaaS)
- Software as a Service (SaaS)

### Week 2 – Terraform and AWS

I used Terraform to automatically deploy an AWS EC2
virtual server running Linux and Nginx.

**Technologies:** Terraform, AWS EC2, Linux, Nginx

### Week 3 – Amazon S3

I created and hosted a static website using Amazon S3.

**Technologies:** AWS S3, HTML, Cloud Storage

### Week 4 – Google Firebase

I developed a dynamic Cloud Notes application.

Users can add, display and delete notes stored in
Cloud Firestore.

**Technologies:** Firebase, Firestore, JavaScript

[Visit my Cloud Notes application](https://oamk-cloud-week4.web.app)

### Week 5 – Browser Automation

I created an automation script that opens the OAMK
website, extracts information and saves it to JSON.

**Technologies:** JavaScript, Node.js, Playwright
